# 노원구 민방위 대피시설 최적 입지선정 분석

노원구 내 민방위 대피시설의 공간적 취약 지역을 분석하고 최적의 신규 후보지를 선정하기 위한 GIS 공간분석 프로젝트입니다.

---

### 분석 진행 단계 및 작업 내용

**1. 기본 공간 데이터 구축 및 좌표계 통일**
* 노원구 행정동 경계, 도로중심선, 민방위 대피시설 위치 데이터 수집 및 QGIS 로드
* 정확한 공간 연산을 위해 좌표계를 **EPSG:5179 (KGD2002 / Unified CS)**로 통일

**2. 행정동별 인구밀도 산출**
* **속성 데이터 결합**: 행정동 경계 레이어에 인구 및 세대수 데이터(CSV/XLSX) 조인
* **면적 및 인구밀도 계산 (Field Calculator)**:
  * 면적 계산 ($km^2$): `AREA_KM2` = `$area / 1000000`
  * 인구밀도 계산 (명/$km^2$): `POP_DENSITY` = `총인구수 / AREA_KM2`

**3. 후보지 공간 격자(Grid) 생성 및 영역 추출**
* **격자 생성 (Create Grid)**: 노원구 전체 영역에 **500m 간격의 포인트 격자** 생성
* **영역 추출 (Extract by Location)**: 생성된 격자 중 노원구 행정동 경계 내부(`are within`)에 위치한 후보점만 잘라내어 `노원구_500m` 레이어 구축

**4. 후보지별 기초 데이터 공간 조인 (진행 중)**
* **인구밀도 결합 (Join Attributes by Location)**: 추출된 500m 격자점에 속한 행정동의 `POP_DENSITY` 값 매핑
* **최근접 거리 계산 (Join Attributes by Nearest)**:
  * 각 후보점에서 가장 가까운 **민방위 대피시설까지의 거리** 계산
  * 각 후보점에서 가장 가까운 **주요 도로까지의 거리** 계산

---

### 향후 계획
* 입지 적합도 평가를 위한 가중치 산정 (인구밀도, 기존 대피소 거리, 접근성)
* 최종 입지 우선순위 후보지 도출 및 시각화
